# QA-ACCEPTANCE.md

## Critical User Journeys

### Parent
1. Register/login.
2. Create child.
3. Select age.
4. Select goals.
5. Complete assessment.
6. View recommendation.
7. View progress.
8. Change settings.

### Child
1. Enter child mode.
2. Start activity.
3. Answer correctly.
4. Answer incorrectly.
5. Retry.
6. Complete session.
7. Continue journey.

## Regression Checklist

- authentication
- authorization
- child ownership
- content rendering
- progress persistence
- recommendation
- audio mute
- reduced motion
- responsive layout
- empty state
- error state
- offline/degraded state
- content approval
- privacy
