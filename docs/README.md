# Learning App — Agent Handoff

Files:
- PRD.md — product requirements and architecture direction
- DESIGN-SYSTEM.md — visual design and anti-slop rules
- VRD.md — atomic implementation roadmap
- CONTENT-SPEC.md — initial 100-activity content plan
- SECURITY-PRIVACY.md — security and child privacy requirements
- QA-ACCEPTANCE.md — QA and acceptance checklist

## Recommended execution order

1. Audit repository.
2. Resolve architecture conflicts.
3. Implement foundation.
4. Implement data model/auth.
5. Implement child profile.
6. Implement activity engine.
7. Implement learning flow.
8. Implement progress.
9. Implement parent dashboard.
10. Implement content pipeline.
11. Seed/review 100 activities.
12. Perform privacy/security QA.
13. Perform anti-slop visual QA.
14. Deploy.

Do not jump directly to Phase 13 just to make the app look full.

The product is successful only if the learning loop works reliably.
